      Updating an existing test installation

      This release adds atomic batch calls and aligns pending responses with the updated node. Unpacked extensions require a manual update.

      Download and verify the new ZIP. Replace the files inside the same extension folder you previously loaded, then click Reload on its card in chrome://extensions and reload this page. Keep the folder path; do not remove the extension to update it, since removal can erase its local wallet data.

      Older entries under Transactions → Custom Network may show Fee unavailable. Use Refresh receipt to retrieve the actual fee without resending a transaction. Unpacked builds do not update automatically.
